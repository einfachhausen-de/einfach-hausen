# Ansprechpartner · neue Arbeitsreferenz

Status: Root-Kandidat nach Ginas ausdrücklicher Zurückweisung. Keine behauptete visuelle Nutzerabnahme.

Modus: Operate. Eigenheimbesitzer suchen die Person für eine konkrete Leistung oder speichern ihre bestehende Hausbeziehung. Die Oberfläche muss als ruhiges Adressbuch funktionieren, nicht wie eine Marketing-Landingpage. Maßstab ist eine moderne Kontakt-/Dateiverzeichnis-Navigation: klare Hierarchie, sichtbarer Rückweg, ein Datensatz pro Person/Betrieb, gezielte Aktionen. Keine Übernahme fremder Logos, Farben oder Claims.

Erster Viewport: Ansprechpartner, eine kurze Handlungsanleitung, dezenter Verwaltungszugang; darunter ausschließlich die 17 Hauptkategorien in einer gemeinsamen weißen Navigationsfläche. Kein Hero, keine Zähler, keine illustrative Person, keine bunten Gewerke-Symbole. Die Gestaltung wird aus dem vollständigen Root-Quelltext angewendet, nicht von einem Implementer frei ausgelegt.

Folgeansichten: Unterkategorien in maximal zwei Spalten; Kontakte als Zeilen mit Namen/Betrieb/Leistungen, eine stabile ID. Detail: Kontaktdaten neben Leistungen; bestehender Chat darunter, falls tatsächlich zulässig. Anlegen/Bearbeiten auf einer eigenen Arbeitsseite, nicht im Modal. Originalauswahl klar sichtbar, weitere Leistungen in einer optionalen Aufklappgruppe.

Bewertung: ein gebündelter Satz echter Desktop-/Tablet-/Mobile-Screenshots mit gefüllten und leeren Zuständen, Formularfehlern, Mehrfachzuordnung und echtem Plattform-Chat. Root sieht die Bilder selbst. Maximal ein gebündelter Korrekturpass für Darstellungsfehler; fachliche oder Sicherheitsfehler müssen unabhängig davon behoben werden. Kein weiteres offenes Designkarussell.
